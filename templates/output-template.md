# 选题输出模板

按用户要求数量输出，不强制三题或多形态。先给首选或暂定优先项及理由。

每题：标题 / 象限 / 唯一受众与任务 / 核心收益 / 为什么现在做 / 开头切口 / 推进顺序 / 来源与日期 / 已有证据或planned测试 / 去重范围与结论 / 可选CTA及入口状态 / 商业承接假设 / 观测指标。

只在需要数字比较时显示当前百分制分数及扣分；不可称作爆款概率。台账不完整时标“暂定优先”，不称已去重或可发布。只在请求周安排时给排期，只在请求多形态时扩展平台表达。


内容简报content_brief先于象限与结构：具体人和处境、关切及其依据/假设、预期观众变化、材料支持关系、未知与分歧、帮助范围及不足、表达方式。定义见 moonlit-business-copywriter/references/content-first-principles.md。CTA允许null，纠错与确定结论不是必填要求。
