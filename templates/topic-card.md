# 单条选题卡

复制此卡到"内容台账"中，发布后回填数据。

## 模板

```markdown
## [标题]

- 选题 ID：T[YYYYMMDD]-[序号]
- 日期：[YYYY-MM-DD]
- 象限：[Q1/Q2/Q3/Q4]
- 主任务：[识别/共鸣/认知/方法/证明/立场/转化/筛选]
- 账号：[月明水情深 / 月明智能科技 / 产品实验号]
- 目标人群：[职业+阶段+场景]
- 用户任务：[正在完成什么]
- 场景阻力：[可命名阻力]
- 核心观点：[一句话核心命题]
- 新角度：[反常识入口]
- 证据：[具体来源]
- 传播锚点：[可截图画面]
- 最小动作：[读者能做的一件最小的事]
- 唯一 CTA：[扣关键词 / 私信 / 扣数字]
- 证据等级：[已确认决策 / 有证据判断 / 待验证假设 / 创作推演]
- 风险标签：[5 红线 + 12 心法逐条]
- 8 维打分：[N]

### 形态与发布

- 发布平台：[公众号 / 小红书 / 视频号 / 抖音 / B站]
- 形态：[朋友圈 / 小红书图文 / 公众号长文 / 短视频 / 漫画 / H5]
- 标题公式：[12 公式中选了哪几个]
- 标题字数：[N]（需满足平台限制）
- 钩子段范文：[≤150 字]
- 目录：[3-5 个 H2]
- 金句海报：[3 张主题]
- 短视频镜次表：[如有]
- 漫画分镜：[如有]
- H5 流程：[如有]

### 发布后回填（P2 启用）

- 阅读：[N]
- 点赞：[N]
- 收藏：[N]
- 评论：[N]
- 线索：[N]
- 转化：[N]
- 备注：[本次选题表现评估 + 下次改进]
```

## 使用方法

### 步骤 1：复制模板
选中上方 `## [标题]` 至最后一个 `---` 的全部内容，复制到台账（飞书表格 / Notion / Markdown 文件）。

### 步骤 2：填字段
按选题方案填齐所有字段。证据等级必填，决定这条选题的可发布边界。

### 步骤 3：发布后回填
发布后回填阅读/点赞/收藏/评论/线索/转化数据，并写一句"下次改进"备注。

### 步骤 4：触发数据闭环
每攒 5-10 条回填数据后，触发 skill 的"复盘反哺"功能（references/07-data-loop.md）。

## 与 8 维打分的对应

| 台账字段 | 来源 |
|---|---|
| 核心观点 | 选题方案 #6 |
| 新角度 | 选题方案 #5 |
| 证据 | 选题方案 #3（引用依据） |
| 传播锚点 | 选题方案 #5（判断依据） |
| 8 维打分 | 选题方案打分卡 |

## 与防重复台账的对应

每次新增选题前，先在防重复台账查：

```bash
python scripts/topic_ledger.py check --topic "核心命题" --days 30
```

近 30 天同核心命题 + 同主要受众不重写（知识库 04 防重复红线）。

## Pitfalls

- ❌ 字段空着发布——台账的价值是数据完整
- ❌ 发布后不回填——失去数据闭环
- ❌ 防重复不查就发——违反知识库红线
- ❌ 证据等级模糊——直接写"创作推演"或"内部测试"，不要含糊
