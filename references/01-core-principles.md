# 选题准入判断

准入判断依据当前认可定位、观众任务、材料真实性、使用权限和可执行测试。内容首要原则由当前激活 `moonlit-business-copywriter/references/content-first-principles.md` 维护。

- 事实或权限风险先处理，不用高热度抵消。
- 没有完成去重或测试就标明缺口，允许暂定选题，不冒充可发布成稿。
- 探索、理解、开源分享、真实经历均可成立；不要求每题获客、有 CTA 或预测会爆。
- 两条模糊警告不自动等于淘汰，判断它们实际影响的结论。

四象限评分按当前激活 `moonlit-topic-radar/references/quadrant-scoring.md`；JEV 实践匹配是另一口径，不能混算。外部方法论仅在已安装且适用时辅助，不是本 Skill 的隐式必需依赖。
