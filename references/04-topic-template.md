# 选题卡

每条围绕一个核心命题，按本次输出需要记录：

- 标题、目标受众与具体任务、观众收益。
- 为什么现在做、已有证据及来源、未知与验证计划。
- 内容角度、必要大纲、与近期命题的区别。
- 当前定位匹配、可执行时间和成本、可沉淀资产。
- 评分口径及限制（采用时）、状态、后续观测指标。
- CTA 可无；采用时与本期任务和真实入口一致。

当前研究交接契约由 `moonlit-benchmark-research/references/research-contract.md` 维护。无需为了套模板安装 topic-planner，也不要求所有字段向用户展开。已存在的 topic_id 在 pick 时保留，作品 ID 由工作区维护工具分配。
