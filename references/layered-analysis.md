# 选题多层分析（唯一定义处）

生成、评估、修订选题卡时必读。本文件是七层分析和两档规则的唯一定义处。其他 Skill（04 模板、选题卡模板、已选题合同、content-first-principles、topic-radar、video-script、benchmark-research）只引用、只核对，不复制定义。

多层分析回答「值不值得做、会不会被误解」；七模型（04 模板）负责拆解与交接。两者不互相替代，也不替换 Q1–Q4 评分。都是起稿前、录制前的检查，不授权助手改作者的观点或口播。

## 适用范围

**【小 idea 也先论证】** 月明随口提的小 idea 也先走基础档：观众任务、现在的办法、为什么不够、前提句、最可能的反驳、来源。在讨论中把分析给月明看，论证清楚后才进入写稿或制作。商单和 P0 也不跳过这一步。

JTBD（L1）是每题必填，不分工具题和其他题。

## 七层（一层只问一个问题）

| 层 | 只问一个问题 | 方法来源 |
|---|---|---|
| L1 用户任务 | 观众在什么情境下想办成什么事？现在「雇用」什么办法？为什么会「解雇」它？ | JTBD（[Christensen 研究所](https://www.christenseninstitute.org/theory/jobs-to-be-done/)）；Job Story（[Klement](https://jtbd.info/replacing-the-user-story-with-the-job-story-af7cdee10c27)）；功能/情感/社会三维 |
| L2 认知差 | 我们默认观众知道、其实他不知道的是哪一句？不先说这句他就听不懂或不信？ | 知识的诅咒（[Camerer 等 1989](https://www.journals.uchicago.edu/doi/10.1086/261651)）；信息缺口（[Loewenstein 1994](https://www.cmu.edu/dietrich/sds/docs/loewenstein/PsychofCuriosity.pdf)） |
| L3 凭什么是月明 | 这题月明有什么真经历、真材料，别人讲不出？ | 选题卡「本人凭什么讲」；topic-radar 的 quadrant-scoring 硬门槛 |
| L4 别人怎么做 | 同题谁做过、怎么讲的、哪里可借、哪里我们不一样？ | 对标拆解：moonlit-benchmark-research 的结构卡与评论需求规则 |
| L5 反驳与阻力 | 观众最强的一句反驳是什么？他不愿换的理由（焦虑、习惯）是什么？在哪回应？ | Rapoport 规则（[Dennett](https://www.themarginalian.org/2014/03/28/daniel-dennett-rapoport-rules-criticism/)）；四力模型（[jobstobedone.org](https://jobstobedone.org/the-four-forces/)） |
| L6 论证骨架 | 能不能用「现状—变化—问题—答案」四句讲通，答案是一句可以被反对的判断？ | SCQA 金字塔原理（[Minto](https://barbaraminto.com/)） |
| L7 预先验尸 | 假设发出 7 天后翻车了，最可能的 3 个原因是什么？各怎么预防？ | Pre-mortem（[Klein，HBR 2007](https://hbr.org/2007/09/performing-a-project-premortem)） |

L1 写法：写标题和大纲前，先按 Job Story 写观众任务：「当［情境］时，我想［进展］，以便［结果］」，不写产品名。再列观众现在「雇用」的 2–3 个替代方案，优先写免费、本地、系统自带和「什么都不做」，逐个写出在什么条件下会「解雇」它（功能必填，情感、社会可选）。从「解雇」理由推出本方案成立的前提，写成一句必须在正文或口播前段说出口的前提句。每项标场景来源（作者亲述/评论原话/对标评论/推断），推断项须作者确认。替代方案只比同类产品、不比观众手边做法的，视为未完成。

L6 只检查核心观点站不站得住，大纲仍按 04 模板第 6 节写。L7 结果里属于 05 风险清单的项直接引用清单，不重复写。

## 两档

### 触发

| 档 | 什么时候用 | 谁定 |
|---|---|---|
| 基础档（L1、L2、L3、L4 简版、L5 一句） | 所有进「待审」的卡，包括对标推荐、雷达三题和月明随口提的小 idea | 建卡人建卡时必填 |
| 加深档（七层全做） | 暂定（触发条件待月明确认）：① 优先级 P0；② 来源为商单；③ 月明说「好选题/重点做/标杆」；④ X 标杆长文、深度长文或预计备料超过半天；⑤ 和复盘过的翻车题同类 | ①② 看字段；③ 月明口头定；④⑤ 建卡人提议并在修改记录写一句理由，月明不同意就降回基础档 |

加深档最晚在「待审 → 已定题」之前做完。对标类卡未被 pick 前只做基础档。

### 基础档字段（放在选题卡「定位连接」之后，见 [选题卡模板](../templates/topic-card.md)，6 行）

- 观众任务：当……时，我想……，以便……（不写产品名）
- 他现在用的办法：2–3 个（先写免费、本地、系统自带、「什么都不做」）
- 为什么不够用：功能原因一句
- 必须说出口的前提句：一句人话，进正文/口播前段
- 最可能的一句反驳 → 我们怎么回：一行
- 来源：每项标「作者亲述 / 评论原话 / 对标评论 / 推断」；推断项同时列入「待补项」

每行不超过手机两行，超出的内容进加深档。

### 加深档字段（卡内折叠块「加深论证」）

1. L1 展开：触发情境；情感、社会两个维度（可无）。
2. L2 认知差：作者默认、观众不知道的 2–3 句；开头要先抛出的那个问题。
3. L4 对标深拆：至少 3 个，按 benchmark-research 结构卡写开头承诺、段落功能、证据、可借、不可借，标明「只读标题 / 读了全文」。
4. L5 三条反驳加阻力：先用观众自己的话写到对方会点头，再写回应和大纲落点；四力里的焦虑、习惯各一句。
5. L6 SCQA 四句，每句标「有证据 / 待测」。
6. L7 预先验尸：3 个原因各配一条预防动作，写进大纲或素材清单。
7. 月明口述确认清单：所有推断情境、需要作者本人经历或数字的地方。

### 合格标准

基础档合格（可进待审，也可在讨论中拿给月明看）：
- 观众任务没有产品名，是观众的话；
- 「现在用的办法」至少 1 个是观众手边做法，不只列竞品；
- 前提句能从「为什么不够用」推出，外行听得懂；
- 反驳是观众真会说的话，不是稻草人；
- 关键情境只有「推断」时，已列进待补项。

退回补：只列竞品、写不出前提句、反驳是自问自答、对标没有 https 链接。

放弃或降到观察池：写不出「为什么不够用」又找不到别的人群；L3 空着；与近 30 天核心命题相同（沿用 quadrant-scoring 去重规则）。

加深档合格（可从待审改「已定题」）：七层都填；SCQA 每句有证据或标待测；三条反驳在大纲里都有落点；验尸 3 因都有预防动作；对标至少 3 个并标阅读深度；月明口述项已确认或月明明确说先不管。

加深档退回或降档：某个验尸原因没有预防办法就改题或缩小承诺；核心论断核实不了，或截图、隐私、商单冲突解决不了，就降回基础档观察或放弃；口述项一直没确认，可以先写，但卡保持「待审」。

## 下游怎么接

- 数据字段：`topic_analysis.layered_analysis`（见 04 模板交接字段）；content_brief 以 `layered_analysis` 引用，下游只读核对。
- 写稿、写脚本、剪辑只继承、只核对前提句和反驳回应，不重新做任务分析；缺了就退回选题卡补。
- 助手只负责把「前提句没说到」报给作者，按「作者表达优先：信达雅」由作者决定怎么补。
