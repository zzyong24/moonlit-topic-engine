# 四味原料

> ⚠️ **本文件只描述方法骨架**。爆款 4 基因的具体定义、月明 4 象限的具体维度名、基因与象限的映射表 → 每次调用前**动态读知识库 + 通用方法论**获取。

## 通用方法：基因 × 象限 双轴定位

任何选题可以用**两个轴**定位：

- **横轴**：传播力底色（爆款基因）
- **纵轴**：任务定位（选题象限）

定位清晰 → 选题不会"四不像"。

## 横轴：爆款基因（半通用）

**通用 4 基因**（来自 viral-topic-forge，可作为默认骨架）：
- 情绪 / 信息差 / 身份 / 行动

**业务专属基因**：知识库可能有补充项（如月明知识库的"立场 / 证明"等）。

**读取路径**：知识库 04-内容选题与栏目系统/四维选题与防重复.md（搜索"主任务 / 基因"）。

**判定规则**（通用）：
1. 主基因必填 1-2 个，缺一不可
2. 次要基因 1-2 个
3. 主基因缺失 → 选题没传播力 → 重写
4. 4 基因全缺 → 选题是"知识搬运" → 必须加独家视角

## 纵轴：选题象限（动态）

**象限数量和命名**：业务决定。

**读取路径**：知识库 04-内容选题与栏目系统/四维选题与防重复.md（搜索"象限 / Q1 / Q2 / Q3 / Q4"）。

**判定规则**（通用）：
1. 每个选题必须归属一个主象限
2. 主象限决定内容主任务（识别/共鸣/认知/方法/证明/立场/转化/筛选）
3. 跨象限需求 → 拆为 2 条独立选题
4. 例外情况：以知识库 04 定义为准

## 跨轴匹配检查（每次必跑）

```
1. 读知识库获取本业务的"4 基因"和"4 象限"定义
2. 标每个选题的主基因（1-2 个）+ 次基因（1-2 个）
3. 标每个选题的象限归属
4. 查知识库的"基因 × 象限最佳匹配表"
5. 匹配不佳 → 调整基因或象限
```

## 基因补强工具（通用）

| 基因弱 | 补强方法 |
|---|---|
| 情绪弱 | 加具体场景 + 痛点人物 |
| 信息差弱 | 加内部数据 / 真实案例 / 独家视角 |
| 身份弱 | 加 3 层标签（职业 + 阶段 + 场景） |
| 行动弱 | 加最小动作 + 唯一 CTA |

具体补强话术 → 看场景，不在本文件写死。

## Pitfalls

- ❌ 把基因定义或象限名写进本文件——业务可能改
- ❌ 4 基因全缺却硬选象限——选不出就换原料
- ❌ 跨象限硬合一——拆成 2 条独立选题更可控
- ❌ 不读知识库直接套"通用 4 基因"——可能漏掉业务专属基因
