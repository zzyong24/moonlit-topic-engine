# 传播角度发散参考

只在候选选题的入口不清楚时使用。先按 `moonlit-business-copywriter/references/content-first-principles.md` 判断具体受众任务、材料和预期收益，再按当前 `moonlit-topic-engine/SKILL.md` 选象限。情绪、信息差、身份和行动是可选的表达视角，不是必填基因或评分项；不能据此推断传播量。

| 需要澄清的地方 | 可尝试的提问 |
|---|---|
| 情绪 | 受众在这个具体处境里真实在意什么？有来源吗？ |
| 信息差 | 哪项可核验的机制、对照或案例能帮助理解？ |
| 身份 | 具体是哪个人群、阶段和场景？标签是否来自材料？ |
| 行动 | 观众看完需要尝试什么吗？若无需行动，可以自然结束。 |

一个选题仍需一个主要受众任务和核心命题。跨象限线索先看能否由同一任务自然承接；不能承接时再拆题。CTA 仅在确有承接目标且入口可用时加入，不为补齐表格承诺资料或服务。
